# L.N.X AI - Frontend Interface

Interactive, sci-fi themed conversational voice AI learning interface.

## Tech Stack

- **Framework**: React 18 + TypeScript
- **Bundler**: Vite
- **UI & Styling**: Tailwind CSS, ShadCN UI (Radix Primitives)
- **Animations**: Framer Motion
- **State & Routing**: TanStack Query, React Router DOM
- **Voice / Speech**: Web Speech API & ElevenLabs Voice Engine

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

The frontend will run on `http://localhost:8080` and proxy API calls to the FastAPI backend at `http://127.0.0.1:8000`.

### 3. Build for Production
```bash
npm run build
```
